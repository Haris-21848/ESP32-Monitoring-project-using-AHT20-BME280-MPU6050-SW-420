# ESP32-Monitoring-project-using-AHT20-BME280-MPU6050-SW-420
Built an ESP32 monitoring system to collect temperature, humidity, pressure, motion, and vibration data. Configured a Mosquitto MQTT broker on Linode to send sensor readings to MQTTX and an OLED display. Learned about MQTT communication, cloud configuration, and sensor debugging through hands-on testing.
